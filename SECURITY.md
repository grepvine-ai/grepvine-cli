# Security policy

Please report a vulnerability privately, not in a public issue: use [Report a vulnerability](https://github.com/grepvine-ai/grepvine-cli/security/advisories/new) on GitHub, or email **security@treeverse.io**.

Include the `gv --version` output, the steps to reproduce the problem and the impact you expect. We'll acknowledge your report, keep you informed while we fix it, and credit you when the fix is released, unless you'd rather not be named.

Security fixes go into the latest release.
